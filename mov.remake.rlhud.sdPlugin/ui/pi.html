Your ranks

MMR fills in by itself from the game log when you start a queue for a single playlist (the value from before the match) — the MMR typed here is a fallback. The game does not write a per-playlist rank or division, so you enter those. Unranked modes (casual, free play) show “UNRANKED” instead of a rank.
